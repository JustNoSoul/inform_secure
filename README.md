# inform_secure
Программа с регистрацией и авторизацией пользователей, использующая следующие технологии шифрования:
1. Тип симметричного шифрования: блочный
2. Используемый режим шифрования: сцепление блоков шифра
3. Добавление к ключу случайного значения
4. Используемый алгоритм шифрования: SHA
Данные пользователи хранятся в зашифрованном json-файле users.dat. При первом запуске программы в консоле предлагается выбрать пароль, на основе которого будет произведено шифрование базы данных. При последующих запусках в начале необходимо ввести пароль для расшифрования файла. После успешного расшифрования, расшифрованный файл появляется в папке с программой.

Цель данной программы - изучить различные типы шифрования на основе простой программы по администрированию пользователями
